# 评分锚点参考

> 7 维度的 1-5 分判定标准。评分基于**实际执行结果**，不是文档分析。

---

## 评分总览

| 分数 | 含义 | 色标 |
|------|------|------|
| 5 | 完美执行，无任何问题 | 🟢 绿 |
| 4 | 基本完美，有极小瑕疵 | 🔵 蓝 |
| 3 | 能用，但有明显改进空间 | 🟡 黄 |
| 2 | 有问题，影响使用 | 🟠 橙 |
| 1 | 不可用/崩溃 | 🔴 红 |

---

## 各维度锚点

### 1. 输出质量

| 分 | 判定 |
|----|------|
| 5 | 输出精确完整，可直接使用，格式规范 |
| 4 | 输出正确，有极小格式问题 |
| 3 | 输出基本正确，但粗糙/有遗漏 |
| 2 | 输出有错误或关键信息缺失 |
| 1 | 无输出 / 输出乱码 / 完全偏离意图 |

### 2. 稳定性

| 分 | 判定 |
|----|------|
| 5 | 相同输入两次执行，核心结论完全一致 |
| 4 | 核心一致，措辞有正常 LLM 波动 |
| 3 | 大部分一致，偶尔有差异 |
| 2 | 经常不一致 |
| 1 | 每次结果都不同 |

### 3. 幻觉检测

| 分 | 判定 |
|----|------|
| 5 | 零幻觉，所有事实可追溯 |
| 4 | 基本无幻觉 |
| 3 | 有少量不精确但不误导 |
| 2 | 有明显编造 |
| 1 | 大量编造，输出不可信 |

### 4. Prompt 遵循

| 分 | 判定 |
|----|------|
| 5 | 100% 遵循 SKILL.md 定义的流程和约束 |
| 4 | 核心约束遵循，极少遗漏 |
| 3 | 主要约束遵循，有明显遗漏 |
| 2 | 部分核心约束未遵循 |
| 1 | 严重偏离指令 |

### 5. Tool 调用

| 分 | 判定 |
|----|------|
| 5 | 工具选择正确、参数精准、有错误恢复 |
| 4 | 基本正确，少量可优化 |
| 3 | 能完成任务但方式不优 |
| 2 | 工具用错或参数错误 |
| 1 | 完全不会用声明的工具 |

### 6. 上下文记忆

| 分 | 判定 |
|----|------|
| 5 | 跨轮次完美保持偏好 |
| 4 | 核心偏好保持 |
| 3 | 近期偏好保持，远期遗忘 |
| 2 | 记忆弱，频繁需重复 |
| 1 | 每轮都重置 |

### 7. 异常处理

| 分 | 判定 |
|----|------|
| 5 | 所有边界场景优雅处理 |
| 4 | 主要边界覆盖 |
| 3 | 基本异常有处理 |
| 2 | 仅处理最常见异常 |
| 1 | 遇异常就崩溃 |

---

## 综合判定

**单 Skill PASS 条件**：7 维中 ≥ 5 个 ≥ 3 分，且无任何维度 = 1 分

| 状态 | 标记 | 含义 |
|------|------|------|
| ✅ PASS | pass | 满足通过条件 |
| ❌ FAIL | fail | 不满足通过条件 |
| ⏭️ SKIP | skip | 外部依赖不可用 |
| ⏰ TIMEOUT | timeout | 执行超 120s |
| 💥 ERROR | error | 执行报错 |
