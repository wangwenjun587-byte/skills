# 冒烟测试用例模板库

> 按 Skill 类型分类的冒烟测试设计模板。调度执行时从中选取最简单的 happy path 用例。

---

## 使用方式

为每个 Skill 设计冒烟测试时：
1. 判断 Skill 类型
2. 从对应分类中选取模板
3. 填充具体的输入和预期
4. 每个 Skill 只需 **1 个冒烟测试**（核心路径）

---

## 文本处理类

### 去AI味 / humanizer

| 项目 | 内容 |
|------|------|
| 类型 | 文本改写 |
| 输入 | 一段含明显 AI 痕迹的英文段落（3-5 句话） |
| 预期 | 输出去除了 AI 词汇，保留了核心意思 |
| 验证点 | 有输出 / 输出与输入相关 / AI 词汇（"Moreover"、"Additionally"等）被替换或删除 |
| 超时 | 30s |

### 内容总结 / summarize

| 项目 | 内容 |
|------|------|
| 类型 | 信息提取 |
| 输入 | 一个公开可访问的 URL（如 Wikipedia 文章） |
| 预期 | 输出该页面的内容摘要 |
| 验证点 | 有摘要输出 / 摘要内容与 URL 主题相关 / 长度合理（>50字） |
| 超时 | 60s |

### AI交叉审查

| 项目 | 内容 |
|------|------|
| 类型 | 文本分析 |
| 输入 | 一段中等长度的技术文档 |
| 预期 | 输出审查意见/问题列表 |
| 验证点 | 有结构化输出 / 包含具体建议 |
| 超时 | 45s |

## 数据查询类

### neodata-financial-search

| 项目 | 内容 |
|------|------|
| 类型 | API 数据查询 |
| 输入 | "腾讯控股今日股价" |
| 预期 | 返回包含价格数据的结构化结果 |
| 验证点 | 有数据返回 / 数值 > 0 / 包含价格字段 |
| 超时 | 30s |
| 前置 | 需要有效 token（无则标记 skip:no_credentials） |

### westock-data

| 项目 | 内容 |
|------|------|
| 类型 | 结构化行情查询 |
| 输入 | "sh600519 实时行情" |
| 预期 | 返回 JSON 格式行情数据 |
| 验证点 | 有 JSON 输出 / 含 price/change 字段 / 数值合理 |
| 超时 | 30s |
