# 抖音-超级私信

## Skill Text Header
- Skill: `抖音-超级私信`
- Skill ID: `douyin-web-send-dm`
- Entry: `scripts/task_entry.py`
- Execution: 本地 Chrome + CDP
- Scope: 指定目标用户主页 -> 打开私信 -> 输入并发送

# 抖音 Web 私信发送

## 核心能力

1. 接收目标用户输入（CSV / 手动抖音号 / 手动主页链接）
2. 标准化目标用户结构
3. 读取本地状态，跳过已发送目标
4. 打开用户主页
5. 检查是否存在私信入口
6. 使用固定文案或回退文案
7. 输入并发送私信
8. 将处理结果写入本地状态文件和运行日志
