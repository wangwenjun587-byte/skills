# 抖音-流量截胡

## Skill Text Header
- Skill: `抖音-流量截胡`
- Skill ID: `douyin-web-competitor-comments-csv`
- Entry: `scripts/task_entry.py`
- Execution: 本地 Chrome + CDP
- Scope: 竞品账号 -> 热门视频 -> 评论用户采集 -> 名单导出 / 后续触达准备

默认入口：`scripts/task_entry.py`

默认执行模型：**本地 Chrome + CDP**。
不要优先走 Playwright；不要把实验脚本当正式入口。

## 输入参数

必填：
- `account`：竞品账号（优先抖音号）

可选：
- `limit`：目标条数，默认 `10`
- `topPosts`：高赞视频数量，默认 `5`
- `enrichId`：是否补抓用户抖音号，默认 `true`
- `dmCount`：私信人数上限，默认 `0`
- `dmPromptHint`：私信开场白提示词
- `dryRun`：仅演练不发送，默认 `true`
- `enable3chatLog`：是否写 claw skill log，默认 `false`
- `cookie`：3chat 登录 Cookie；当 `enable3chatLog=true` 时会注入内置 `claw_skill_log.py` 使用

参数映射：
- `account -> --account`
- `limit -> --limit`
- `topPosts -> --top-posts`
- `enrichId -> --enrich-id`
- `dmCount -> --dm-count`
- `dmPromptHint -> --dm-prompt-hint`
- `dryRun -> --dry-run`
- `enable3chatLog -> --enable-3chat-log`
- `cookie -> --cookie`

## 日志说明

- 当 `enable3chatLog=true` 时，入口脚本会直接调用内置 `scripts/claw_skill_log.py` 中的 `ClawSkillLogClient`。
- `create_execution_log` 成功后读取返回的 `log_id`。
- DM 批次中每条结果使用 `append_data` 追加。
- DM 阶段结束与任务结束时分别使用 `update_execution_log` 回写 `successed_count`、状态与摘要。
- `cookie` 会被注入到 `CLAW_SKILL_LOG_COOKIE_20140711`，供内置日志客户端自动带到请求头。

## 运行约束

- 依赖由宿主环境提供；skill 目录不提交 `.venv/`。
- 脚本间调用统一使用宿主 Python（`sys.executable` / `python3`），不要再依赖 `uv run` 作为子脚本执行入口。
- CDP 仅允许连接本地 `127.0.0.1` / `localhost`。
- 默认启用业务预算与强制中断，避免页面等待、评论抓取或整任务长时间卡住。
- 在 macOS Apple Silicon 上，Chrome 启动必须强制走 `arch -arm64`；否则在当前 CoPaw x86_64 / Rosetta 执行上下文里，Chrome 容易误以 x64 方式启动并显著变慢。
- 日志能力统一走 skill 内置的 `scripts/claw_skill_log.py`，不再依赖外部 `3chatclaw_skill_log.py` 命令行脚本。

## 默认流程

1. 打开抖音搜索页并确认竞品账号主页
2. 提取主页视频并按点赞排序选前 N 条
3. 逐个进入视频详情页读取评论区用户
4. 可选进入用户主页补抓抖音号
5. 合并去重并导出 CSV
6. 当 `dmCount > 0` 时，按去重后的用户列表进入主页私信

## 私信规则

- `dmCount = 0`：只采集，不私信
- `dmCount > 0`：按结果顺序选前 N 个用户私信
- 私信前必须先按用户维度去重
- 必须过滤目标账号本人
- 私信默认走最短稳定链路：`用户主页 -> 单击私信 -> 输入 -> 发送`
- 单个用户失败时继续后续用户，不要整批中断
- 每个用户都要记录 `pending / sent / blocked / error`

推荐私信脚本：
- `scripts/douyin_dm_simple_send.py`
- `scripts/douyin_dm_batch_simple.py`

## 输出

固定 CSV 表头：
- 用户名称
- 用户抖音号
- 评论内容
- 所属视频
- 所属竞品账号

## 关键规则

- 不从整页文本盲抓评论
- 评论只认评论容器
- 评论用户名和 `user_profile_url` 必须对应
- 视频只认主页视频卡片链接
- 页面结构变化时，优先更新 `references/selectors-and-notes.md`
