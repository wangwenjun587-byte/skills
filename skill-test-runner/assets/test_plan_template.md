## 第二步：设计测试用例

### 用例 1：正常路径测试（Happy Path）

```
测试维度：输出质量 / Prompt 遵循
测试 Prompt：
  ← 填写典型使用场景的 Prompt

期望输出特征：
  - ← 格式要求
  - ← 必须包含的内容
  - ← 不应包含的内容
```

### 用例 2：稳定性测试

```
测试维度：稳定性
操作步骤：
  1. 清空上下文
  2. 运行用例1的 Prompt
  3. 记录结果A
  4. 重复步骤1-3，记录结果B和C
  5. 对比三次结果

对比维度：
  - 核心结论是否一致
  - 格式是否相同
  - 关键数字/代码是否一致
```

### 用例 3：幻觉探测测试

```
测试维度：幻觉检测
测试 Prompt：
  ← 设计一个要求输出具体事实的 Prompt
    （版本号、API名称、代码等可验证内容）

验证方法：
  ← 如何核实（官方文档URL / 实际运行 / 搜索等）
```

### 用例 4：约束遵循测试

```
测试维度：Prompt 遵循
测试 Prompt（包含多个约束）：
  "← 正向要求1，
   ← 正向要求2，
   不要← 负向约束1，
   禁止← 负向约束2，
   输出格式：← 格式约束"

检查项：
  □ 正向要求1是否满足
  □ 正向要求2是否满足
  □ 负向约束1是否规避
  □ 负向约束2是否规避
  □ 输出格式是否符合
```

### 用例 5：异常输入测试

```
测试维度：异常处理
测试用例列表：
  a. 空输入：发送 ""
  b. 超长输入：发送 500 字随机文本
  c. 矛盾指令：← 设计矛盾指令
  d. 非法参数：← 发送格式错误的参数
```

### 用例 6（可选）：多轮上下文测试

```
测试维度：上下文记忆
轮次设计：
  第1轮：← 引入关键约束（如"使用Python 3.11, 变量用小驼峰命名"）
  第2轮：← 执行基础任务
  第3轮：← 引入新要求，同时验证第1轮约束是否保留
  第4轮：← 要求整合所有之前内容，检验长程记忆
```
